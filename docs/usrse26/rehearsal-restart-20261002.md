## Lessons that save time next time

1. Start with the existing evidence and runbooks: `docs/usrse26/platform-evidence/usrse260930/README.md`, `docs/usrse26/public-demo-cutover-20260930.md`, and `docs/usrse26/public-demo-showtime-notes-20260930.md`. Reuse the tested two-org baseline, then add the real third Fabric org; a database-only organization is not enough. The observed third-org path took 28.8 minutes of operator-led elapsed time, including a corrected peer join. It is not an automated provisioning claim.
2. Use the run-scoped `prepare-run.ps1`, `prepare-aws-artifacts.ps1`, and `deploy-aws-platform.ps1` in the **runtime owner checkout**; use `prepare-demo-control.ps1` in the **edge owner checkout**. Review each generated plan against the correct local state and run ID. The source paths are references, not a license to replay old state into a new run.
3. The EKS API is private-enabled with its public control endpoint restricted to the operator's observed `/32`. If the laptop/VPN address changes, verify the current address before `kubectl`; update only that narrow allowlist. Do not open the control endpoint or Argo CD to the world. Argo access was a localhost-only port-forward.
4. Publish the static site only after the private ALB, Argo `Synced/Healthy`, Fabric confirmation, and `/api/v1/health` are verified. The Angular runtime config is ignored and must be uploaded separately with `API_BASE_URL=/api/v1` and `MOCK_PREVIEW=false`. Use a guarded, distribution-only Terraform plan for the CloudFront API attach. The default is detached. Test negative routes, WAF limits, CSRF, ownership, file-manifest bounds, account/artifact/workflow/history, and desktop/mobile accessibility before replacing the read-only index. The earlier public-origin browser check passed these paths, but a new environment must be tested anew.
5. Demo write access can be `CLOSED` even while the page and API are public. Open it deliberately through the private demo-status endpoint for the planned time window, without printing the Kubernetes auth secret. `ExpiresAt` metadata is not an automatic shutdown timer. Keep a human teardown reminder and a cost watch.
6. For shutdown, reverse the exposure order: restore the read-only S3 index **and** `READ_ONLY` `status.json`, invalidate CloudFront, then detach `/api/*` with the targeted-plan guard and wait for `Deployed`. Leaving an old live `status.json` with `applicationUrl` can cause a redirect loop. Remove the CloudFront VPC origin before EKS teardown; its deletion took about seven minutes this time. Then run the EKS destroy, followed by the separate edge/control destroy.
7. The runtime destroy script did not cover the exact-name release S3 bucket, IAM permissions boundary, one org3 credential-rotation EBS snapshot, or three Fabric CA root secrets. Inventory found them after Terraform reported success; they required scoped cleanup. A deleted security group and its rules still appeared in the Resource Groups Tagging API after direct EC2 queries returned not found; that caused inventory parity to remain false even with no run remnants. Verify with the service APIs as well as inventory; never claim success from Terraform alone.
8. The control destroy removed 76 Terraform resources but its release cleanup failed because an absent S3 delete-marker array contributed a null item to the delete batch. Thirteen exact release object versions and the empty, run-tagged bucket were removed manually. The script now filters null entries and deletes the bucket only after tag and empty-bucket checks. One unattached, manually created recovery IAM policy was also outside Terraform and needed exact-ARN cleanup.
9. The new-org evidence was 71 to 76 ready pods on the same three worker nodes. Do not describe node groups as organization pods or claim pod readiness equals a working org. Check channel MSP membership, chaincode, an artifact and workflow with readable Fabric history, public catalog visibility, and cross-org denials. The one-in-90 API transaction-pointer mismatch during a fault test remains an unresolved limitation, not a clean provenance result.
